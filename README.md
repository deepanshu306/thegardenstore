# The Garden Store

**Live:** https://thegardenstore.in

## What it does
E-commerce website for garden products with product and category listings and an admin backend.

## Features
- Product and category structure
- Admin management flows
- Polished, responsive UI

## Tech Stack
- PHP • JS • HTML/CSS • MySQL

## Preview
![Preview](https://api.microlink.io/?url=https%3A%2F%2Fthegardenstore.in&screenshot=true&meta=false&embed=screenshot.url)

## Run locally
1. Clone this repository:
   ```bash
   git clone https://github.com/deepanshu306/thegardenstore.git
   cd thegardenstore
   ```
2. Set up a local PHP environment (e.g., XAMPP/WAMP).
3. Import the database schema (if provided) and update connection details.
4. Serve the application and visit in your browser.

## Usage
- Browse products and categories.
- Admin users can manage products, categories, and other data in the admin panel.
